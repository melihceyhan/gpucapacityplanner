Hardware pricing

GPU / Node unit cost

Cost = selected whole-block deployment GPUs × GPU unit price, or deployed nodes × node unit price. This is hardware-only input pricing: networking, storage, racks, cooling, taxes and installation are excluded. Extra theoretical GPUs are not purchased in the calculation.

Power model: Each room has an independent IT limit. Compute budget = IT capacity × (1 − reserve). Facility capacity requirement at full IT load = IT capacity × PUE. Real facility draw needs measured network/support load. GPU count always rounded down to complete 8-GPU nodes. The planned deployment rounds down to complete 32-node or 72-node blocks; remaining node capacity is shown separately. The % reserve is a budget allowance, not verified actual equipment draw. It does not cover cooling/UPS losses (PUE does).

Networking design guidance

32-node design point · Spectrum-X Ethernet

32 nodes = 256 GPUs. HGX B300 Enterprise RA references Spectrum-X Ethernet, with rail-optimized architecture. The 32-node option is treated as one selected planning block (256 GPUs). Internally, the reference design can use smaller modular groupings, but these are not exposed as selectable options.

72-node DGX SuperPOD SU · Quantum-X800 InfiniBand

72 nodes = 576 GPUs. This refers to the distinct NVIDIA DGX B300 SuperPOD SU architecture. It cannot automatically be substituted into a HGX 32-node network design. Both paths require rack, cabling, power, storage and vendor validation.

Important: The extra GPUs displayed are theoretical power headroom only; adding them can require a custom fabric/partial-block design. Whole-unit fitting is calculated independently per 1 MW room. A 72-node SU cannot be split across rooms in this model; capacity across rooms is not pooled. The operating mode power values are screenshots' system-level inputs, not a measured BOM or a guarantee of system throughput.
